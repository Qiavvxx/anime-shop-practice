# Java-прототип интернет-магазина аниме-мерча

Учебный ООП-вариант Python-прототипа из отчёта по практике. Программа показывает поиск товаров, создание заказа с проверкой наличия и резервированием, а также два исхода оплаты.

## Что реализовано

- поиск активных товаров по названию и франшизе, с фильтрами по категории, франшизе и доступному остатку;
- проверка корзины, объединение повторных позиций и фиксация цены на момент заказа;
- резервирование товара только после проверки всех позиций;
- успешная оплата: резерв снимается, физический остаток уменьшается;
- отклонённая оплата: резерв снимается, физический остаток остаётся прежним;
- модель доставки через базовый класс DeliveryMethod и варианты CourierDelivery и PickupDelivery;
- интерфейс PaymentGateway и учебный эмулятор ответа платёжного сервиса.

Данные хранятся в памяти. База данных, настоящий платёжный шлюз и служба доставки не подключены.

## Структура

- src/main/java/ru/mirea/animeshop/Main.java — демонстрационный запуск;
- model — товар, покупатель, заказ, позиции заказа и статусы;
- delivery — способы доставки;
- payment — интерфейс и эмулятор оплаты;
- service — поиск, оформление заказа и обработка оплаты;
- data — демонстрационный каталог.

## Требования

Установленная Java 17 или новее. Сторонние библиотеки не нужны.

## Запуск на macOS или Linux

Из папки проекта выполни:

    bash run.sh

## Запуск в Windows PowerShell

Из папки проекта выполни:

    .\run.ps1

Если Windows блокирует запуск сценария, открой папку проекта в IntelliJ IDEA или VS Code с поддержкой Java и запусти Main.java. Также можно выполнить команды компиляции и запуска из терминала IDE.

## Что должно появиться

Демонстрация находит два товара по запросу «Наруто», оформляет заказ на фигурку и мангу, показывает успешную оплату, затем показывает отклонённую оплату по брелоку. При отказе оплаты количество брелоков не уменьшается.

Для ручной проверки нехватки товара измени количество в корзине на число больше доступного остатка. Заказ должен завершиться ошибкой до изменения резерва.
